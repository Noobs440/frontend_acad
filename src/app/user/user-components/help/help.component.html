Centre d'aide & Support utilisateur

Bienvenue dans la page d'assistance de la plateforme de gestion et d'archivage des rapports de projet du département informatique de l’Université de Dschang.


📘 Guides rapides

  • Soumettre un projet : Accédez à "My Projects" → "Upload" → remplissez le formulaire → cliquez sur "Envoyer".
  • Modifier votre profil : Cliquez sur votre image de profil → "My Profile" → modifiez et sauvegardez.
  • Consulter vos projets archivés : Tableau de bord → liste de vos projets → cliquez sur un titre pour voir les détails.
  • Recevoir des notifications : Les notifications s'affichent via la cloche 🔔 dans le header.

❓ Questions fréquentes (FAQ)

Q : Puis-je modifier un projet déjà soumis ?
R : Non, mais vous pouvez supprimer et soumettre une nouvelle version.

Q : Comment être sûr que mon rapport est visible par mon encadreur ?
R : Une fois soumis, le statut du projet passe à "En attente de validation", et un message est envoyé à l'encadreur.

Q : Qui peut voir mes projets ?
R : Seuls les enseignants encadreurs, administrateurs et utilisateurs autorisés peuvent les consulter.

Q : Que faire si je n’arrive pas à me connecter ?
R : Vérifiez vos identifiants, sinon utilisez la page de récupération ou contactez l’assistance.
